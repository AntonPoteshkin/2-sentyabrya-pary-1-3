# Мини-графический редактор

Программа демонстрирует основные принципы объектно-ориентированного программирования на примере работы с геометрическими фигурами.

---

## 1. Название и описание задачи

Программа создает геометрические фигуры, вычисляет их площадь и управляет координатами через защищенные методы.

---

## 2. Архитектура проекта

### Инкапсуляция

В классе Figure координаты _x и _y скрыты. Доступ к ним возможен только через методы get_coords и set_coords.

### Наследование

Базовый класс Figure наследуют классы Circle и Square.

### Полиморфизм

Все фигуры используют единый метод calculate_area. Для круга площадь вычисляется по формуле pi * radius^2, для квадрата side^2.

---

## 3. Пример использования

from shapes import Circle, Square

figures = [
    Circle(0, 0, 5),
    Square(10, 10, 4)
]

for fig in figures:
    print(fig)
    print(fig.calculate_area())
